# Web Core Frontend

React frontend application built with Vite, TypeScript, Tailwind CSS, and styled-components.

## Development

```bash
yarn start        # Start the Vite development server
yarn build        # Build for production
yarn test         # Type-check the frontend

The development server for Cypress runs on port 8080 via `yarn start:test`.
```

## Environment Variables

Create a `.env.local` file with:

```env
VITE_API_URL=http://api.app.local
```
